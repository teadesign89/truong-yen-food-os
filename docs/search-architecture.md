# TRƯỜNG YÊN FOOD OS — Search Architecture

## 1. Nguyên lý

> Search là đường tắt cấp cao nhất của hệ thống.

Người dùng không cần biết một Object nằm trong Module, Folder hay Document nào.

Người dùng chỉ cần biết mình muốn tìm gì.

---

# 2. Search Objective

Search phải đưa người dùng:

Search
→ Object
→ Workspace

Mục tiêu:

- Tìm nhanh.
- Hiểu kết quả ngay.
- Mở đúng Object.
- Giữ nguyên ngữ cảnh.
- Không yêu cầu người dùng hiểu cấu trúc hệ thống.

---

# 3. Search Entry Points

Search phải có mặt tại:

- Global Header
- Dashboard
- Workspace
- Mobile Navigation

Global Search là điểm truy cập thống nhất.

---

# 4. Search Types

Search hỗ trợ:

- Object Search
- Knowledge Search
- Document Search
- Output Search
- Related Object Search

---

# 5. Object Search

Người dùng có thể tìm:

- Product
- Brand
- Company
- Packaging
- Supplier
- Process
- QA Review
- Document
- Output

---

# 6. Search Query

Search có thể sử dụng:

- Tên
- Mã Object
- Từ khóa
- Loại Object
- Trạng thái
- Phiên bản
- Quan hệ
